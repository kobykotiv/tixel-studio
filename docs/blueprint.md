# **App Name**: Tixel

## Core Features:

- Image Upload: Upload a single source image for tiling.
- Tiling Grid Selection: Select tiling grid dimensions (2x2, 4x4, 8x8, custom YxY).
- Tiled Texture Preview: Preview the generated tiled texture in real-time.
- Image Tiling: Serverless function processing images one at a time.
- Secure Download Link: Generate a secure download link for the zipped processed images.
- Batch Tiling: Tool to select multiple source images and tile them with the same tiling options. Tiling happens asynchronously in the background and informs the user of its completion. Includes a queue where tiling tasks are listed
- Premium Tier Features: Enable exclusive, resolution of image batch uploads.

## Style Guidelines:

- Dark mode background (#121212) for comfortable viewing and modern aesthetic.
- Primary color: Electric blue (#7DF9FF) for interactive elements.
- Accent color: Vibrant green (#00FF00) for success states and highlights.
- Font: 'Inter', a sans-serif typeface for a clean and modern look for both headings and body text.
- Use simple, geometric icons with the primary electric blue color (#7DF9FF) for a consistent look.
- Mobile-first responsive layout with clear, intuitive navigation.
- Subtle transitions and loading animations to provide visual feedback and enhance the user experience.
